# 🏥 AI-Powered Health Prediction System

A comprehensive healthcare management system with AI-powered health predictions based on blood test results.

## Features

✅ **Complete CRUD Operations**
- Create patient records
- View all patients
- Update existing records  
- Delete records

✅ **AI Health Predictions**
- Analyzes Glucose, Haemoglobin, and Cholesterol levels
- Generates risk scores (0-100)
- Provides clinical recommendations

✅ **Data Validation**
- Email format (Gmail only)
- Date of birth (cannot be future)
- Numeric blood value validation

✅ **Persistent Storage**
- SQLite database for permanent storage

## Tech Stack

- **Backend:** Python 3.9+
- **Framework:** Streamlit
- **Database:** SQLite3
- **AI/ML:** Custom Rule-based Expert System
